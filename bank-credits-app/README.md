# Оптимизация кредитных услуг банков РБ

Веб-приложение для анализа и сравнения кредитных продуктов банков Республики Беларусь.

## 🚀 Запуск

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## 📋 Функционал

### Главная страница
- Общая статистика по банкам и кредитным продуктам
- Обзор банков-участников с ключевыми показателями
- Типы кредитов со средними ставками

### Сравнение кредитов
- Фильтрация по типу кредита (потребительский, авто, ипотека, обучение, овердрафт)
- Сортировка по ставке, сумме и сроку
- Таблица с детальными данными по всем продуктам

### Кредитный калькулятор
- Выбор кредитного продукта из списка
- Расчёт аннуитетных и дифференцированных платежей
- Отображение ежемесячного платежа, переплаты и общей суммы
- График платежей на первые 6 месяцев

### Рейтинг банков
- DEA-рейтинг эффективности банков
- Топ банков по доле рынка
- Топ банков по кредитам физическим лицам
- Аналитические выводы

## 🎨 Дизайн

Приложение следует принципам skill `frontend-design`:
- **Типографика**: Playfair Display (заголовки) + Source Sans 3 (текст)
- **Цветовая схема**: Тёмная тема с акцентным синим цветом
- **Анимации**: Плавные появления с каскадной задержкой
- **Композиция**: Карточный интерфейс с эффектами наведения

## 🛠 Технологии

- **React 19** — UI-библиотека
- **Vite 8** — сборщик
- **React Router 7** — маршрутизация
- **CSS Variables** — темизация

## 📊 Источники данных

Данные основаны на отчёте по преддипломной практике в ОАО «Беларусбанк» и открытых источниках банков Республики Беларусь за 2021-2025 гг.
